# customtailored

Global contains global variables and some minor logic that the entire game runs off of.\n
The main node contains the two maps the game has: the factory map 'factory' and the tower defense map 'td_map'.\n
'basicenemy', 'turret', and 'projectile_td' are components of 'td_map'\n
All other scenes are part of 'factory', although 'floor' is reused for visual purposes\n
