# customtailored

Global contains global variables and some minor logic that the entire game runs off of.
The main node contains the two maps the game has: the factory map 'factory' and the tower defense map 'td_map'.
'basicenemy', 'turret', and 'projectile_td' are components of 'td_map'
All other scenes are part of 'factory', although 'floor' is reused for visual purposes
